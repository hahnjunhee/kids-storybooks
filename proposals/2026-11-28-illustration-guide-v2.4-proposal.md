# 이미지 제작 가이드라인 v2.4 개정 제안
- 작성: 2026-11-28
- 상태: 검토안 / Claude 의견 및 사용자 승인 대기
- 기준: docs/ILLUSTRATION_STYLE_GUIDE_V2.3.md (실제 제목 v2.3.1)
- 범위: 제작 절차와 이미지 품질 통제. 기존 작품, 운영본, 배포 코드는 변경하지 않는다.

## 1. 회고 및 근거
혈액 동화 v2.0은 13장 내장 HTML 461,316 bytes로 main에 등록했다. 파일 수집 과정에서 Space 항목과 Page/GitHub를 혼동했고, 일부 압축본의 원본 바이트 접근이 제한되어 PNG 원본으로 대체했다. 생성 완료와 파일 확보, 검수 합격, 배포 확인을 구별해야 한다. 실제 모바일 및 Pages 접속 검증은 미완료다.
05 혈장 운반, 07 혈소판 지혈, 10 딱지 관찰은 핵심 행동 표현 개선 후보이며 기존 배포본 교체는 별도 승인 사항이다.
그림체 변화의 확인 가능한 원인 후보: 기존 BASE는 cinematic 2D animated storybook, clean linework, painterly shading, directional light인 반면 혈액 작품은 hand-painted watercolor anime 및 rounded friendly characters 중심의 짧은 문구를 사용했다. 참조 시트가 새 대화에 실제 첨부되지 않으면 시각 정보 전달을 보장할 수 없다. 소재와 새 캐릭터 시트의 영향도 가능하다. 모델 버전 변경 여부는 미확인. 기존 6권 원본 전수 비교 전에는 화풍을 확정하지 않는다.

## 2. 유지 및 변경
- 사용자 확정 방향: 메인 대화에서 개별 프롬프트 작성, 장면마다 새 대화에서 단독 생성. 동일 대화 기본 규칙은 개정 대상으로 표시.
- A/B/C 체계, 4:3, 개인정보 보호, 독립 이미지 생성, 원본 오류와 조립 오류 구분, 콘택트 시트 유지.
- 기존 B는 풍경·상황 중심이다. 발견형을 B에 포함할지 검토하되 기존 분류를 무단 변경하지 않는다.
- C는 아이 및 의인화 캐릭터 제외, 과학 정확성 우선. 기존 사실적 관찰 표현과 C-1/C-2 한국어 학습 텍스트 필수 유지. 글자 없는 생성 원본과 HTML 합성 완성 카드를 구별한다. 도해 예외 유지. 수채화 C형 허용 여부는 검토 후 결정.
- 기존 공개 운영본의 1~2MB 권장과 최근 사용자 요구 500KB 이하 사이의 차이를 명시한다. 신규 단일 HTML은 500,000 bytes 목표로 제안하며 과학 가독성 저하 시 승인된 예외를 기록한다.

## 3. Style Master / Character Master
기존 승인 작품에서 A/B/C 대표 삽화를 선정하여 스타일 기준 v1.0을 확정한다. 신규 생성으로 기존 화풍을 대체하지 않는다. A/B는 동일 화풍, C는 기존 관찰 규격을 우선한다. 작품별 캐릭터 시트는 외형·의상·소품만 통제한다. 실제 참조 이미지를 각 새 대화에 첨부하고 참조 ID/버전을 원장에 기록한다. 첨부 없이 이름만 언급하면 참조 적용 확인으로 인정하지 않는다. 비공개 캐릭터 및 참조 원본은 공개 저장소에 올리지 않는다.
기존 BASE를 초기 기준으로 유지하고, 과도한 광택·채도·판타지 효과 억제 문구는 대표 삽화 비교 후 결정한다. 유형별 실제 장면 1장씩 파일럿 승인 후 나머지 생성. 파일럿은 본편에 재사용한다.

## 4. 독립 실행형 프롬프트
각 새 대화에서 이전 맥락 없이 실행 가능해야 한다.
1. 작품 ID/버전/장면 번호/유형
2. 스타일 BASE와 실제 참조 첨부 확인
3. 해당 장면 등장 캐릭터만 정의(비공개)
4. 확정 본문 전문 및 text_hash
5. 핵심 시각 메시지 하나, 주 피사체, 핵심 행동
6. 구도·시점·거리·시간·날씨·회복 단계, 보조 대상
7. 과학 제약 및 비유 범위
8. 장면별 금지 요소와 인접 장면 차별점
9. 4:3 단독 이미지 1장(기존 C-2 완성 카드 예외)
10. 합격 조건, 검수·압축·저장 결과 반환
전체 장면의 구도표를 먼저 설계하되 기계적인 시점 변경보다 교육 목적을 우선한다. 과학 대상 자체가 주인공일 수 있다.

## 5. 검수 게이트
본문 일치 25, 핵심 행동 20, 과학 정확성 20, 캐릭터 15, 차별성 10, 구도 10의 잠정 배점. 각 1~5점 환산, 85 이상 합격 후보, 70~84 보완, 미만 재생성. 해당 없는 항목은 제외 후 재정규화. 과학 오류, 핵심 행동 불일치, C형 아이/의인화, 식별정보, 워터마크, 핵심 피사체 잘림은 점수 무관 불합격. C형 완성 카드의 필수 텍스트 누락도 불합격. 점수는 보조 수단이며 사용자 승인 절차 유지. 원본 정상 시 재생성보다 변환/매핑/조립 오류 점검 우선.
05 예시: 노란빛 액체와 물질 이동 중심, 캐릭터는 보조, 실제 음식 금지. 07: 혈관 벽 손상 부위에 모여 지혈, 전체 혈관 폐쇄로 오인되지 않도록. 10: 며칠 후 딱지 관찰, 초기 지혈 장면과 구별.

## 6. 파일 및 원장
작품별 비공개 작업 공간에 manuscript.md, character-sheet, scene-manifest.json, illustrations/00-cover.webp~12.webp, review/contact-sheet.jpg 관리. 개별 대화 반환명은 {book-id}-v{version}-scene-{NN}.webp. 원본 별도 보존. Space 저장 기능이 없으면 파일 반환 후 사용자 저장, 메인 대화에서 실제 접근 확인. 파일명만으로 완료 인정 금지.
원장 필드: scene_id, type, title, text_hash, prompt_version, style_ref, character_ref, image_file_id, image_path, byte_size, dimensions, review_score, file_verified, status. 본문 변경 시 기존 승인 무효화 및 재검수. 상태: planned → generated → accessible → reviewed → optimized → approved. 중복은 승인 파일 하나만 채택. 공개 원장에 비공개 ID/개인정보 제외.

## 7. 압축·HTML·배포
Base64 약 4/3 증가 고려. 500KB 목표, HTML 오버헤드 25KB 가정 시 이미지 예산 약 356KB. 표지 11%, 일반 서사 52%, 발견 13%, 과학 24%는 예시이며 실제 복잡도와 장면 수에 맞춰 조정. C형 가독성 우선. 실제 바이트 수와 이미지 디코딩, 순서, 외부 의존성 검사. 390px 모바일 및 오프라인 실제 테스트, Pages URL 접속과 서재 연결 확인. 확인 불가 시 미검증 표기. 스와이프/이어읽기/서재 이동은 별도 P2 제안으로 이번 변경 범위 밖.
