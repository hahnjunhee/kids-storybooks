# 그림책 낭독 기능 통합 기획안 v1.1
작성: 2026-11-28 | 상태: 통합 기획 승인, Phase 0 청취 결정 완료(A형 채택, 기본 속도 1.15배), 라이선스 위험 수용 결정 대기
기존 GPT v1.0과 Claude 초안을 대체하는 단일 기준 문서. 실제 구현 및 배포 승인은 단계별 검증과 구분한다.

## 1. 목표 및 범위
모든 기존 8권 및 신규 그림책 상단에 듣기 기능을 추가한다. 기존 작품 소급 금지 원칙의 예외는 낭독 UI 및 관련 메타데이터에 한정하며 본문·삽화는 보존한다. 실제 최신 목록은 books.json으로 재확인한다.
GitHub Pages에서 사전 생성 MP3를 재생하며 상시 서버는 운영하지 않는다. MeloTTS 한국어 KR 화자를 우선 시험하고 엔진 교체가 가능하도록 설계한다.

## 2. 확인된 시험 기록과 한계
Claude의 2026-11-28 시험 기록(video-test/TTS_RESEARCH.md 참조): 전기뱀장어 1~3장 CPU 합성 성공, 장면당 17~21초, 약 0.15초/자, 문장 중간 약 1.1초 및 끝 0.8~1.4초 무음, 설치 의존성 약 5GB. 실시간 대비 속도 표기는 측정 단위를 재확인한다. GPT 독립 재현 및 실제 청취는 미완료. 모델/가중치 라이선스와 배포 조건 확인 필요.

## 3. 사용자 경험
제목 아래 상단바에 🔊 듣기, AI 음성 표시. 사용자 탭으로 현재 장면부터 시작하며 자동재생 금지. 재생/일시정지, 이전/다음, 처음부터, 현재 장면/연속 낭독, 속도는 기본 1.15배(Phase 0 청취 결정), 선택지는 1.0/1.15/1.25/1.35 안(0.9 포함 여부 미정, 1.5배는 제외 가정, 확정 대기). 큰 터치 영역 44px 이상, 접근성 라벨, 인쇄 시 숨김.
세로 모드는 선택적 자동 따라가기, 직접 스크롤 시 따라가기만 중지하고 재개 버튼 제공. 좌우 모드는 장면 종료 시 자동 넘김. 모드 전환 시 재생 위치 유지. 수동 페이지 이동 시 재생 중이면 해당 장면으로 이동, 정지 중이면 자동재생하지 않음. 마지막 장면 종료 시 정지. 오류 시 기존 읽기 유지 및 재시도 제공. 오프라인 여부만으로 버튼을 비활성화하지 않는다.

## 4. 구조와 구현
Claude 조사 기준 .spread(루루, 해달, 영흥도, 전기뱀장어), 일반 section(craft-museum, blood-friends, lua-pink-bicycle), 별도 구조(dinosaur). header 없는 두 권 및 루루 외부 이미지 구조도 고려. 실제 DOM과 장면 수는 Phase 1에서 전수 확인하고 안정적인 scene_id, 문단 선택자, 상단 삽입 위치를 책별 어댑터로 확정한다. 공룡은 section 수를 장면 수로 간주하지 않는다.
공통 플레이어 소스는 tools/narration/ 아래 단일 관리하고 빌드 시 각 HTML 및 templates/storybook.html에 인라인 삽입한다. HTML 독립 읽기 유지, 외부 라이브러리 없음. 중복 삽입 방지 및 버전 검사.
audio/<book-id>/sNN.mp3, mono 48~64kbps. HTML 내 JSON manifest: schema_version, player_version, book_id, scene_id, selector, paragraph_selectors, audio_url, duration, paragraph_start_seconds(후속 단계), text_hash, synthesis_hash, audio_hash, engine, model_version, speaker, settings, review_status.
text_hash는 표시 본문, synthesis_hash는 낭독용 텍스트·발음 사전·모델·생성 설정·후처리 버전을 포함한다. 변경 장면만 재생성하고 해시 불일치/미검수 음성은 배포 차단. 오디오와 manifest는 함께 갱신한다. 상대 URL 및 캐시 무효화 검증.
HTMLAudioElement 하나, preload=none, 사용자 재생 이후 다음 장면만 선택적 프리페치. 재생 실패/빠른 연속 조작/모드 전환 시 중복 이벤트 방지. Media Session은 지원 감지 후 후속 적용, 잠금화면 지속 재생 보장 금지.

## 5. 생성 및 품질
tools/narration/ 생성 도구: 장면 추출 → 낭독 텍스트 정규화 → 합성 → 무음 및 음량 조절 → MP3 → manifest → 검수. 초기에는 기존 클라우드 세션에서 생성하고 결과만 커밋. GitHub Actions는 경량 검증부터 사용하며 합성 자동화는 환경 재현성 확인 후 검토. 의존성/모델 버전 고정.
문단 강조는 문단별 합성 후 PCM 병합 및 실제 시작 시간 기록 방식과 장면 전체 합성 비교 후 결정. 문단 간 자연스러운 억양을 우선하며 최종 MP3 기준 동기 확인.
낭독 범위: 제목·소제목·본문, 발견 노트 및 학습 카드는 본문과 구분한 선택 낭독. 표지 소개·쪽 번호·제작 메모·삽화 설명 제외. 발음 치환은 표시 본문을 변경하지 않는다. 실명 및 실제 아동 목소리 복제 금지.
샘플 평가 1~5점: 발음 25, 자연스러움 25, 어린이 친화 음색 20, 속도/호흡 15, 편안함 10, 연결성 5. 가중합 80 이상 채택 권장, 65~79 보완, 미만 대체 엔진 검토. 발음 3점 미만 또는 의미 변경/누락은 점수와 무관하게 재검수. 이 기준은 운영 제안이며 실제 청취 승인 필수. 전 장면 청취 기록 유지.

## 6. 용량 및 오프라인
MP3 직접 커밋을 기본으로 하되 실제 측정 후 확정. 5분 48~64kbps 약 1.8~2.4MB, 8권 약 15~20MB는 추정. HTML 증가 3KB 목표는 실측하며 기존 500KB 목표와 충돌 시 별도 검토. 오디오 Base64 내장 금지. 단일 HTML 오프라인 읽기 유지, 음성 오프라인은 보장하지 않음. 캐시된 음성은 재생 시도, 실패 시 안내 및 재시도. 서비스워커는 범위 밖.

## 7. 단계 및 완료 기준
- Phase 0: 샘플 청취, 발음/무음/음색 평가, 라이선스 확인. 통과 전 본 구현 금지. 결과와 잔여 조건은 §9.
- Phase 1: 전기뱀장어 시범, 전체 책 구조 조사, 상단 플레이어/속도/장면 이동/자동 넘김/해시 검증. 실기기 승인.
- Phase 2: 공통 생성 도구 및 템플릿, 나머지 책 한 권씩 적용, 제작 가이드 v3.1.3 낭독 절 반영(실제 최신 버전 확인 후 번호 확정).
- Phase 3: 문단 강조, 잠금화면 제어, 재접속 이어듣기, 홈 카드 낭독 배지. 선택 기능 실패가 핵심 낭독을 방해하지 않도록 한다.
검증: 원문 누락/추가 없음, 해시 일치, MP3 디코딩 및 URL HTTP 200, Android Chrome/Samsung Internet 및 데스크톱 재생, 320~480px 레이아웃, 키보드, 저장소 차단, 오프라인/오류, 모드 전환, 연속 조작, 인쇄, 기존 삽화/본문 회귀 검사. 자동 검사와 실제 청취/실기 검증을 분리 기록. 실패 시 해당 책만 이전 버전 복구.

## 8. 결정 기록
통합 방향은 사용자 승인. 전체 소급 적용, MP3 직접 등록, 선택 학습 낭독, 가이드 개정은 통합안의 기본 정책으로 채택하되 실제 용량·가이드 버전 검증 필요. 음질은 미승인 상태. plan-pipeline 교차 검토 절차의 공식 완료 여부는 별도 확인한다. 이번 변경은 문서만 대상으로 한다.

## 9. Phase 0 결과 (2026-11-28)
청취: 사용자가 폰에서 시험 페이지(https://hahnjunhee.github.io/kids-storybooks/narration-test/)를 듣고 판단했다. §5의 가중 평가표는 쓰지 않고 청취 소감으로 결정했다. A형(MeloTTS 원본)을 채택한다. 재생 속도는 1.15배가 가장 듣기 좋았고, 1.25배도 좋았고, 1.35배는 들을 만했다. 1.5배는 평가 언급이 없었다. 결정: 음성은 A형, 기본 재생 속도는 1.15배.
한계: 보호자 청취 기준이다. 대상 연령(4~6세) 아동의 실청취와 안드로이드 실기 재생은 Phase 1에서 확인한다. B형(무음 최적화)과 C형(느린 합성·호흡 조절)은 채택하지 않았으므로 §5의 무음·음량 조절 단계는 기본 적용하지 않고 필요할 때 다시 검토한다. 문단 사이 무음은 원본 그대로이므로 장면 전환 호흡은 Phase 1에서 다시 확인한다.
라이선스(공개 문서 대조, 법률 자문 아님): 코드는 MIT(LICENSE, README). 한국어 모델은 Hugging Face 카드가 MIT이고 접근 제한과 추가 사용 제한 문구가 없다. 함께 쓰이는 BERT(kykim/bert-kor-base)는 Hugging Face 카드에 표기가 없고 원 저장소 README가 Apache-2.0으로 밝힌다. 의존 패키지는 Apache·BSD·ISC 등 허용적이며 우리 저장소에는 포함하지 않는다. 미해소: 한국어 모델의 학습 데이터와 화자 출처가 공개되어 있지 않아 데이터셋 라이선스와 화자 동의의 영향을 확인하지 못했다. 상태는 조건부이며 이 위험을 수용할지는 사용자 결정 대기다. 화면의 "AI 음성" 표시는 유지한다.
우리 쪽 정리: video-test의 Pretendard 폰트(OFL-1.1)에 라이선스 고지 파일이 없다. 고지 추가 또는 제거가 필요하며 별도 결정 대기다. 낭독 UI와 시험 페이지에서는 이 폰트를 쓰지 않는다.
Phase 1 착수 조건: 라이선스 위험 수용 결정, 속도 선택지 확정.
