# 이미지 제작 가이드라인 v2.4 — 최종 합의안
2026-11-28 / 사용자 승인 방향 반영 / PR #10 검토 브랜치 보관
이 문서는 기존 제안서와 Claude 코멘트의 충돌을 정리한 최종 변경 명세다. 병합 전 운영 원본은 v2.3.1 및 제작 v3.1이다.

## 우선순위
사용자 명시 결정 > 기존 승인 가이드라인 > 신규 제안. 아래 명시 변경 외 기존 규칙 전부 유지. 기존 작품 소급 변경 금지.

## 확정 변경
1. A/B 기존 시네마틱 2D BASE 및 유형 정의를 그대로 유지한다. 수채화로 전면 전환하지 않는다. 기존 골든 샘플 2~3장 체계를 활용하며 Style Master는 기존 화풍의 대표 참조라는 의미로만 사용한다. 별도 버전 관리 체계는 만들지 않는다. 대표 이미지 실제 선정은 신규 작품 준비 시 검증 후 승인한다.
2. 메인 대화에서 확정 스토리보드와 장면별 독립 프롬프트를 작성하고 실제 생성은 장면마다 새 대화에서 한 장씩 순차 진행한다. 기존 v3.1 중복 실행 금지, 생성 전 차단, 시도 예산 및 상태 전이를 유지한다.
3. 참조는 실제 첨부 확인 필수. A 및 인물 포함 B는 스타일+캐릭터 참조, 인물 없는 B는 스타일만, C는 과학 관찰/도해 참조만 사용한다. 표지는 등장인물에 따라 적용. 참조 누락 시 확인 요청. 비공개 자료 공개 금지.
4. 독립 프롬프트 6블록: 참조 확인 / 작품·장면·유형 / 기존 BASE·스타일 / 해당 캐릭터(없으면 생략) / 확정 본문·핵심 순간·행동·구도·시간·날씨·과학 제약 / 출력·금지·합격 조건·파일명. 기존 §7 BASE, FORMAT, TYPE, NEGATIVE 및 C형 프롬프트의 내용을 보존한다. 장면 구도표는 기존 스토리보드에 한 줄로 통합한다.
5. C형 아이 및 의인화 캐릭터 금지. 기존 사실적 자연관찰, §9 지도·도해 예외(세포·미시 원리 포함), C-1/C-2 한국어 필수 요소 및 모바일 가독성 유지. 글자 없는 원본과 텍스트 포함 최종 카드 구분. A/B 글자 금지 유지.
6. 개별 생성 대화에서 본문·핵심 행동·과학 사실·참조 일치·금지 요소를 즉시 검수하고 저장한다. 메인 대화에서 실제 파일을 열고 전체 콘택트 시트로 화풍·인물·인접 구도·매핑을 재검수한다. 파일명만으로 확보 또는 승인 처리하지 않는다. Space 직접 저장 불가 시 파일 반환 후 사용자 저장 및 재조회. AI가 기록을 담당한다.
7. 신규 삽화 가중 점수제와 별도 원장·상태·DB는 도입하지 않는다. 기존 image-manifest.json, pending/generating/review/approved/stale/blocked, E0~E3, 해시 3종, 최초 1회+수정 2회 및 재개 승인 유지. 기존 작품 전체 품질 보조 점수는 폐기 대상이 아니다. 필수 오류 E0/E1 해결, 경미 E2/E3 원칙 유지. 원본 정상 시 저장·변환·조립 오류 우선 수정. 실제 미실행 검수는 pending. 기존 원장 검수 근거에 파일 접근 결과 기록.
8. 신규 단일 HTML 기본 목표 500,000 bytes 이하. 기존 1~2MB 권장 규격은 승인 예외로 보존. C형 글자는 HTML 합성 우선, 과학 디테일 및 가독성 훼손 금지. 원본 비공개 보존, 배포용 WebP 차등 압축. 초과 시 이유 기록 및 사용자 승인. 기존 작품 소급 없음.
9. 실제 모바일·오프라인 및 공개 URL 검증과 GitHub 등록을 구분. 확인 불가 시 미검증 보고. 신규 자동화나 HTML 편의 기능은 범위 밖.

## 실행 흐름
최초 준비(기존 대표 참조 확인) → 작품별 원고·스토리보드·프롬프트 확정 → 장면별 새 대화 첨부·생성·즉시 검수·저장 → 메인 대화 파일 확보·통합 검수·압축·조립 → 사용자 최종 확인·게시·실제 URL 검증.
신규 첫 작품은 필요한 유형별 실제 장면 파일럿을 먼저 검수하고 본편에 재사용한다. C형 없는 작품에 C형을 강제하지 않는다.
