# 생활동화 삽화 스타일 가이드 — YEONGHEUNG-LIFE v1.0
상태: 테스트용 초안. KSDS v1.1 통합 기획에 따라 작성. 기존 운영 가이드를 대체하지 않는다.
근거: ../references/yeongheung-life/visual-analysis.md
## 1. 시각 정체성
빛이 풍부하고 색채가 선명한 2D 애니메이션풍 디지털 회화. 부드러운 캐릭터 렌더링, 세밀한 배경, 자연스러운 입체 조명, 전중후경 깊이, 장면에 맞는 감정과 색채. 저채도 파스텔 및 종이 수채화 질감을 강제하지 않는다.

## 3. 규칙
MUST: 작품별 캐릭터 마스터 유지, 본문 핵심 행동과 감정 전달, 단독 가로 4:3, 장면 간 동일 이미지 금지, 주요 피사체 불필요한 잘림 방지.
SHOULD: 풍부하고 조화로운 색, 장면에 맞는 자연광, 환경을 통한 서사, 시선과 몸짓으로 사건 전달, 인접 장면의 구도 차별화.
MAY: 역광, 반사광, 낮은 시점, 형태 언어, 동작의 예비 자세, 극적인 원근. 필요한 장면에만.
MUST NOT: 원본의 꽃·바다·분홍 의상·햇살·웃는 표정을 모든 작품에 복제, 스타일 참조 인물의 외형을 다른 캐릭터에 전이, 문자·워터마크·콜라주, 수채화 번짐 강제.
과학 C형 아이 제외 및 기존 개인정보·압축·배포 규칙 유지.
## 4. 장면 명세
기존 명세에 emotion, lighting, palette, shot, style_reference만 추가한다. 별도 DB 불필요. 색은 의미 중심으로 지정하고 원본에서 추출하지 않은 HEX 값을 공식 토큰으로 사용하지 않는다.
## 5. 생성 방식
장면에 적합한 스타일 원본 1~2장과 작품별 캐릭터 마스터를 실제 첨부한다. ID만으로 참조를 대신하지 않는다.
공통 문구: Luminous, richly colored 2D animated storybook painting; soft expressive characters, finely painted environments, believable natural lighting, layered spatial depth. Follow attached style references for rendering only and character reference for identity.
장면별 문구: 핵심 행동, 감정, 장소, 구도, 조명, 필요한 소품. 4:3, single illustration, no text.
## 6. 테스트 계획
동일한 승인 캐릭터 마스터로 아래 3장 생성. 각 장면은 독립 이미지.
T1 실내: 아이가 비 오는 아침 현관에서 장화를 신는다. STYLE-01. 미디엄, 차분한 기대, 흐린 창빛. 바다와 꽃 장식 없음.
T2 야외: 아이가 공원에서 아빠와 낙엽을 발견한다. STYLE-02/04. 낮은 시점, 호기심, 가을빛. 바다 없음.
T3 감정: 아이가 아빠와 저녁 창가에서 멀리 불빛을 바라본다. STYLE-05. 뒷모습, 평온, 따뜻한 실내와 푸른 저녁 대비.
## 7. 검수
화풍25, 본문20, 캐릭터15, 공간15, 행동·감정10, 구도10, 기술5. 잠정 합격90. 본문 불일치, 캐릭터 오류, 중복은 재생성. 실제 어린이 반응은 별도 기록.
## 8. 피드백
승인 사례와 실패 원인을 기존 reference library에 기록. 비핵심 참조 파일 표시 오류는 제외하고 진행하되 핵심 캐릭터 참조 미확보 및 본문 오류는 우회하지 않는다.
## 9. 남은 검증
실제 참조 이미지 전달 가능 여부, 테스트 3장 생성 및 비교, 사용자 스타일 승인, 기존 가이드 충돌 확인, 병합. 현재 main 및 기존 작품은 변경하지 않는다.
