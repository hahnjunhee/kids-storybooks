추가 기획보다 구현 우선. 기존 5권 분석 → 최소 제작 시스템 → 기존 2권 재현 → 신작 1권 시범 제작. 기존 공개 작품 변경 금지.

## Claude 의견 평가
- 구현 부재: 동의. Phase 1 우선.
- P01~P05 하향식 설계: 기존 5권과 대조하여 확정. 혼합·생략 허용.
- 관리 규칙 과중: 부분 동의. 삭제보다 자동화 우선, 신작 실측 후 간소화.
- 규칙 중복: 단일 원본 지정.
- 일부 문서 미검토: 구현에 필요한 원문 확인.
- Phase 1: 순서와 완료 게이트 보완.

## 추가 권고
1. 공통 템플릿은 레이아웃·비율·글꼴·여백·모바일·인쇄·독서 도구를 표준화하되 장면 수, 이야기 흐름, 발견 노트, 비교 카드, 색상 분위기는 작품별 선택으로 유지.
2. 해시 3종, 상태 6종, 재생성 횟수, E0~E3는 스크립트/AI가 처리. 사용자는 방향·만족도·게시 승인에 집중. 신작 1편 이후 부담 평가, 3~5편 실측으로 조정.
3. 규칙 원본: 제작 가이드 v3.1(원고·스토리보드·절차·승인), 이미지 가이드 v2.3.1(화풍·구도·검수·재생성), SPS(실행 구조). 중복 규칙은 원문 대조 후 참조로 대체. proposals/는 설계 이력으로 보존하고 현행 규칙으로 사용하지 않음.
4. 자동 검증과 시각 검수 분리: 파일 존재·디코딩·순서·매핑·중복·해시는 스크립트, 모바일 넘침은 실제 브라우저, 본문/삽화 일치·이미지 내 실명·과학적 정확성·캐릭터 일관성은 AI 시각 검수 및 필요한 사실 확인. 미실행 검사는 PASS 금지.

## Phase 1 실행 순서
1. 기존 대표 HTML 5권 비교: DOM/CSS, 장면, 이미지 저장, 독서 기능, 예외. 버전 보존 파일은 중복 집계하지 않음.
2. 공통/변수 분리: T01~T06 필수·선택, P01~P05 관찰 근거, 구도 카드 4종 대조. 근거 부족 패턴은 잠정 유지.
3. templates/storybook.html 및 장면 데이터 구현: 기존 image-manifest.json 재사용 가능성 확인, 중복 대장 금지. 개인정보·작업 원고·참조 이미지는 비공개.
4. scripts/build_storybook.py 통합 빌드·검증: 독립 HTML, 이미지 내장, 이스케이프·경로 제한, 필수 자산/상태/해시/텍스트 검사. 실패 시 기존 정상 파일 보호. tests/ 최소 회귀 테스트.
5. 일반 생활·체험동화 1권과 공룡 과학동화 1권을 임시 경로에 재현. 기존 이미지 재사용, 신규 생성 불필요. 원문·장면 순서·이미지 매핑·발견 노트·독서 기능·모바일 390px·인쇄 비교. 기존 공개 HTML/URL/책장 변경 금지. 결과 및 미검증 항목 기록.
