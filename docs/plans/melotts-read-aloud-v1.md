# MeloTTS 동화 낭독 기능 도입 기획 v1.0
작성: 2026-11-28 / 상태: 구현 전 검토안

## 목표와 범위
모든 기존 및 신규 동화 상단에 공통 낭독 플레이어를 제공한다. 공개 도서관에서 확인한 6권부터 전수 조사하되 실제 구현 시 최신 목록을 기준으로 한다. 기존 세로 스크롤 및 좌우 넘김 기능, 삽화, 본문은 유지한다.

## 기술 선택
MeloTTS는 한국어 및 CPU 추론을 지원하는 MIT 라이선스 Python 라이브러리다. https://github.com/myshell-ai/MeloTTS
GitHub Pages는 정적 호스팅이므로 Python 추론을 브라우저에서 직접 실행하지 않는다. 빌드 시 장면별 WAV를 생성하고 ffmpeg로 mono MP3 48~64kbps 변환 후 정적 파일로 배포한다. 상시 서버/API 키 없이 HTMLAudioElement로 재생한다. GitHub Actions 수동 실행을 우선 검증하고 실패 시 별도 클라우드 실행 환경에서 생성한 파일을 커밋한다. 모델 및 의존성 버전 고정, 모델 가중치 라이선스 별도 확인.

## UI
제목 아래, 본문 시작 전: [▶ 동화 듣기] [이전 장면] [다음 장면] [속도 0.8/1/1.2] 진행 시간 및 장면 번호. 기본 속도 1.0, 자동재생 금지. 재생/일시정지/이어듣기/처음부터 기능. 연속 낭독과 현재 장면 낭독 지원. 낭독 중인 장면 강조, 좌우 넘김 모드에서는 연속 재생 시 페이지 동기화, 스크롤 모드에서는 선택적 자동 스크롤. 직접 넘기면 재생 중일 때 해당 장면으로 이동, 정지 상태면 자동재생하지 않음. 접근성 라벨, 큰 터치 영역, 오류 시 기존 읽기 유지.

## 데이터 및 공통 모듈 (제안 경로)
- assets/js/read-aloud.js, assets/css/read-aloud.css
- assets/audio/{book-id}/{scene-id}.mp3
- assets/audio/{book-id}/manifest.json: scene_id, audio_url, duration, text_hash, model_version, speaker, synthesis_speed.
- scripts/generate_narration.py, .github/workflows/generate-narration.yml
원문과 장면 ID를 기준으로 추출하고 HTML UI 문구 및 페이지 번호 제외. 한국어 숫자/단위/과학 용어/의성어는 별도 발음 사전으로 처리하되 표시 본문을 변경하지 않는다. 해시에는 낭독용 텍스트 및 생성 설정을 포함하며 변경된 장면만 재생성한다. 불일치 음성은 배포하지 않는다. 산출물 검증 후에만 manifest 갱신.

## 용량 및 오프라인 정책
기존 경량 단일 HTML 목표 유지. 음성은 별도 리소스로 제공하고 preload=none, 사용 시 로딩한다. 5~10분 기준 48~64kbps 약 1.8~4.8MB/권(추정). 단일 HTML 오프라인 읽기는 유지하지만 음성 오프라인 재생은 별도 다운로드 또는 캐시 패키지 도입 전에는 보장하지 않는다. 저장소 증가량을 측정하고 중복 음성 누적을 최소화한다.

## 단계
1. 최신 도서 목록, HTML 장면 구조, 보기 모드, 공통 스크립트 조사.
2. 전기뱀장어 1권으로 한국어 음성 샘플 및 발음 검수. 기본 음색의 적합성과 속도 비교, 사용자 승인.
3. 해당 1권에 플레이어 적용, 모바일 및 데스크톱 시험.
4. 기존 전체 작품에 일괄 적용, 신규 동화 제작 가이드에 음성 생성 및 해시 검수 추가.
5. 배포 후 각 작품 URL, 재생, 장면 연동, 오류 처리 확인.

## 합격 기준
본문 누락/추가 없음, 장면별 해시 일치, 한국어 발음 청취 검수, 상대 경로 및 HTTP 200, Android Chrome/Samsung Internet 및 데스크톱에서 최초 탭 재생/정지/속도/연속 재생/장면 변경 동작, 음성 오류가 읽기 기능에 영향 없음, 기존 삽화 및 레이아웃 회귀 없음. 자동 검사와 실제 청취를 구분해 기록한다.

## 미확인 사항
현재 소스의 실제 DOM 구조, Actions 실행 시간 및 모델 설치 성공 여부, 한국어 화자 품질, 음성 파일 실제 크기는 구현 단계에서 확인한다. 이번 커밋은 기획 문서만 추가하며 실제 기능/워크플로/배포 설정은 변경하지 않는다.
