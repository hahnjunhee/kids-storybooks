# Kids Storybooks UX/UI 개편 기획안 v1.0

2026-11-27 · 제안 단계 (구현 및 배포 미실시)

## 목표
동화 소개 페이지를 100권 이상 확장 가능한 개인 디지털 서재로 전환한다. 기존 그림책 감성과 단일 HTML 오프라인 열람 원칙을 유지한다.

## 화면 및 기능
- 모바일 2열, 태블릿 3~4열, PC 4~6열 표지 카드. 긴 소개는 상세 화면으로 이동.
- 제목·소재·학습 키워드·태그 통합 검색, 카테고리 필터, 최신/제목/최근 읽기/많이 읽기 정렬.
- 홈, 전체 책장, 즐겨찾기, 읽기 기록 하단 고정 메뉴.
- 이어서 읽기, 즐겨찾기, 완독 횟수와 최근 독서일, 오늘의 추천책, 신간 7일 표시.
- 상세 정보: 추천 연령, 읽기 시간, 장면 수, 학습 키워드.
- 실명 대신 닉네임 또는 중립적 서재명.

## 분류
과학(동물·곤충, 공룡·화석, 우주·지구, 물리·화학, 우리 몸), 생활(생활습관, 친구 관계, 마음·감정, 안전), 창작(상상·마법, 모험·여행, 가족), 사회·예술(직업·사회, 세계·문화, 미술·음악). 2단계 분류와 연령·소재·학습 주제·시리즈 태그를 조합한다.

## 읽기 화면
스크롤 모드 유지 및 한 장씩 좌우 스와이프 모드 추가. 글자 크기, 장면 목차, 전체 화면, 읽기 위치 저장.

## 기술 구조
index.html 공통 서재, books.json 메타데이터, assets/ 공통 CSS·JS·썸네일, books/ 개별 HTML (경로는 실제 저장소 확인 후 확정). 검수 승인된 도서만 등록하며 GitHub Actions로 필수 필드·중복 ID·파일 경로 검증 후 배포. WebP 썸네일 20~50KB 목표, lazy loading, 초기 12~20권과 더 보기, 터치 영역 44px 이상. localStorage로 개인 기록 저장(기기 간 동기화 없음, 데이터 삭제 시 유실). Service Worker로 선택적 오프라인 보관. 별도 서버·유료 DB 미도입.

## 단계
1. 메타데이터, 표지 그리드, 검색, 분류·정렬, 하단 메뉴, 실명 제거.
2. 즐겨찾기, 최근 읽기, 위치 저장, 완독 관리, 추천.
3. 읽기 모드, 글자 크기·전체 화면, 오프라인 저장, 자동 등록 및 배포 검증.

## 검증
100권 가상 데이터에서 검색·필터·정렬·모바일 레이아웃 확인, 기존 도서 링크와 오프라인 열람 회귀 테스트, 저장 기록 복원 확인. 실제 모바일 렌더링과 최신 배포 목록은 아직 검증하지 않았다. 본 문서는 이전 대화의 v1 제안을 요약 보존하며 대안 기획과 분리한다.
