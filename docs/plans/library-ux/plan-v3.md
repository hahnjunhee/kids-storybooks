## 결정
단일 책장 화면으로 통합. 제목, 검색, 최근 열어본 책 1권(기록 없으면 숨김), 유형/즐겨찾기 필터, 최신순 기본 도서 그리드. 제목순 선택 가능. 모바일 2열, 넓은 화면 반응형. 표지/제목 직접 열기, 하트는 별도 조작. 검색 중 최근 영역 숨김, 검색 결과 없음 시 초기화 안내. 빈 유형은 노출하지 않음. 최신순으로 신간 표시 대체. 차분한 녹색 강조색은 잠정안, 표지 중심.

## Claude 반영
쉬운 문구, 일관된 카드, 빈 상태 다음 행동, 가족 사용 관찰, 읽기 화면 변경 분리 채택. 상황 질문/mood, minutes, 가로 스크롤, 신간 전용 영역, 별도 전체 보기, 추천, 통계, 하단 메뉴, 회원가입, 설정 페이지 제외. age는 기존 필드 우선 재사용. 카드 클릭은 완독이 아닌 최근 열람으로 기록. 실제 읽기 위치는 후속 검토.

## 기술
기존 index.html 및 books.json 구조 먼저 확인하고 최소 변경. 기존 도서 HTML과 URL, 오프라인 열람 보존. 기존 메타데이터 우선 재사용: 안정적인 id, title, category, tags, age(선택), publishedAt, cover, path. 승인된 최신 버전만 노출. 별도 서버/DB/프레임워크/API 없음. localStorage로 즐겨찾기/최근 열람, 저장 실패 시 기본 탐색 유지. 검색/필터/정렬/스크롤 상태는 뒤로 가기 시 복원. 기존 표지 재사용, lazy loading. 기존 제작·배포 절차에 메타데이터 등록 및 링크/ID 검증만 연계. 실제 경로 및 필드 확정은 코드 확인 후.

## 검수
현재 도서 및 50/100권 가상 데이터에서 제목/태그 검색, 필터, 정렬, 빈 상태, 즐겨찾기 유지, 버전 변경 시 ID 유지, 뒤로 가기 복원, 표지/링크 누락 처리 확인. 모바일 320~480px 및 가로 화면에서 잘림 없음, 터치 영역 44px 이상, 키보드 접근 및 명확한 포커스. 기존 HTML/링크/오프라인 열람 회귀 검증. 실명 노출 제거 범위 확인. 초기 전송량 500KB 이하 목표는 실측 후 판단. 가족 사용 테스트로 특정 책 찾기/최근 책 다시 열기 확인. 분석 도구 미도입.

## 범위 및 한계
기획안만 등록. Claude 브랜치 머지 및 PR 생성, 서비스 코드 수정, 배포는 하지 않는다. 실제 최신 저장소 코드 및 모바일 동작 검증 전이므로 구현 세부사항은 확정하지 않는다. 기존 v1 보존. 후속 기능은 실제 불편이 확인될 때만 추가.
