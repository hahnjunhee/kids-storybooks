# 그림책 이미지 제작 가이드라인 v2.3.1 — 공개 운영본

> 적용일: 2026-11-22 · 기준: 비공개 v2.3 통합본의 공개 가능 규칙
>
> **주의:** 원본 v2.3에는 비공개 캐릭터 외형·기준 이미지·제작 기록이 포함되어 있어 공개하지 않는다. 이 문서는 제작·검수에 필요한 공개 규칙만 정리한다. **C형 텍스트 필수**는 2026-11-22 승인 사항으로 반영한다.

## 0. 핵심 체계

**공통 비주얼 아이덴티티 1개 + 목적별 A/B/C 3유형.** A·B는 같은 시네마틱 2D 애니메이션풍, C는 사실적 자연관찰 이미지와 **반드시 표시되는 한국어 학습 텍스트**로 구성한다.

| 항목 | A 인물·이야기 | B 풍경·상황 | C 관찰·설명 |
| --- | --- | --- | --- |
| 목적 | 행동·표정·감정·상호작용 | 장소·계절·규모·분위기 | 생물·사물의 특징 전달 |
| 화풍 | 따뜻한 2D 애니메이션 | A와 동일 | 고해상도 실사형 |
| 주된 구도 | 인물 중심 미디엄샷 | 풍경 중심 와이드샷 | 대상 근접 사진 + 정보 카드 |
| 인물 | 권장 25~40%; 감정 클로즈업 40~60% | 권장 15~25% 또는 생략 | 원칙적으로 불필요 |
| 텍스트 | 이미지에 넣지 않음 | 이미지에 넣지 않음 | **제목·발견 노트 또는 비교 설명 필수** |
| 비율 | 4:3 가로 | 4:3 가로 | 4:3 가로 |

12장면 기준 A 6~7, B 3~4, C 카드 1~3개는 **권장 배분**이며 원고의 필요가 우선한다. 인물 점유율도 권장값으로 취급한다.

## 1. 공통 비주얼 아이덴티티

- 정교한 2D 애니메이션, 섬세한 색 윤곽선, 부드러운 회화적 채색
- 선명하지만 자극적이지 않은 색감, 방향성 있는 자연광, 은은한 역광·림라이트
- 풍부하되 복잡하지 않은 배경, 전경·중경·원경을 활용한 공간감
- 자연스러운 유아 비율과 장면에 맞는 표정; A·B의 캐릭터 일관성은 **별도 비공개 기준 이미지와 캐릭터 시트**로 관리
- 낮·아침·밤의 조명은 원고의 실제 시간대와 날씨를 우선한다. 맑은 낮의 색상을 흐린 날에 강제하지 않는다.
- 신규 제작 기본 비율은 4:3 가로. 특별한 화면이 필요하면 작품별 승인 후 예외를 기록한다.

## 2. 개인정보·캐릭터 운영

- 공개 그림책에는 실제 아동 이름, 실사진, 학교·집·생활 반경을 식별할 수 있는 정보를 넣지 않는다.
- 이야기 속 별칭은 작품별로 선택하거나 생략한다. 이미지 생성 프롬프트에는 `the child protagonist`처럼 역할 표현을 쓴다.
- 공개된 이미지에는 아동의 이름을 표시하지 않는다. **C형 라벨은 '발견 노트'**로 표기한다.
- 캐릭터의 구체적인 외형 고정문, 참조 이미지, 인물별 시트, 책별 액세서리와 이름 목록은 공개 저장소 밖에서 관리한다.
- 기존 참고 이미지의 이름이나 개인화된 노트 문구를 그대로 재사용하지 않는다.

## 3. TYPE A — 인물·이야기

- 감정·행동·가족 또는 친구와의 상호작용을 중심으로 구성한다.
- 인물은 기본 25~40%, 감정 클로즈업은 40~60%를 참고한다. 연속 클로즈업은 피한다.
- 배경은 행동의 맥락을 이해할 만큼 충분히 표현한다.
- 이미지에 제목·설명·말풍선·문자를 생성하지 않는다.

## 4. TYPE B — 풍경·상황

- 장소·시간대·계절·공간의 규모를 전달한다.
- 와이드샷, 원경, 파노라마 구성과 전경·중경·원경의 깊이를 활용한다.
- 인물은 작게 두거나 생략할 수 있다.
- A와 동일한 그림체를 유지하며 이미지에 문자를 넣지 않는다.

## 5. TYPE C — 관찰·설명: 텍스트 필수

**C형 완성물에는 반드시 한국어 텍스트가 포함되어야 한다.** 사진만 있는 결과물은 C형 완성으로 인정하지 않는다.

- 사진 표현: 자연사 관찰 사진에 가까운 사실적 질감, 실제 서식지, 자연광, 명확한 관찰 대상.
- 정보 표현: 제목, 대상명, 관찰 포인트, 발견 노트·비교 설명을 **읽을 수 있는 한국어**로 제공.
- **권장 제작:** 글자 없는 실사형 이미지를 생성한 다음, HTML/CSS로 제목·설명·강조·아이콘을 합성하여 화면에 함께 표시한다.
- **허용 제작:** 이미지 생성 단계에서 한글을 직접 포함할 수 있다. 단, 맞춤법·누락·글자 왜곡·가독성을 전수 검수하고 오류 시 수정한다.
- **완성 판정은 화면 기준:** HTML로 합성했더라도 이용자가 보는 최종 C형 카드에는 텍스트가 항상 나타나야 한다. 이미지 단독 다운로드가 필요한 경우 텍스트가 포함된 별도 완성본을 내보낸다.
- 실제 촬영 사진이 아닌 생성형 실사 이미지는 실제 관찰 증거로 오인되지 않도록 출처 성격을 구분한다.

### C-1 — 단일 대상 발견 노트

**필수 요소:** ① 대상명이 있는 제목 ② 사실적 대상 이미지 ③ **'발견 노트'** 라벨 ④ 특징을 설명하는 한국어 2~3문장.

- 크림색 둥근 제목 배너, 연한 파란 테두리, 굵은 둥근 고딕.
- 대상명만 주황·파랑 등으로 강조. 노란 발견 노트 탭, 파란 점선 테두리의 크림색 설명 상자.
- 형광펜 강조는 핵심어 1~2개, 조개·불가사리·물방울 장식은 최대 2개를 권장.
- 설명 상자는 대상을 가리지 않는 하단 또는 우측에 배치. 약 25~30% 면적은 시작값이며 모바일에서는 사진 아래 별도 카드로 이동 가능.
- 한 문장은 약 25자 안팎을 권장하지만 **사실 정확성과 자연스러운 문장**을 우선한다.
- 한 줄 포인트 말풍선은 필요한 경우에만 사용.

### C-2 — 비교·정리 카드

**필수 요소:** ① 카드 제목 ② 실사형 관찰 이미지 2~3개 ③ **각 대상의 한국어 이름표** ④ **각 대상의 특징을 설명하는 한국어 문장**.

- 사진과 설명을 시각적으로 짝지어 혼동하지 않게 배치한다.
- 모바일에서는 가로로 억지로 축소하지 않고 세로 카드로 재배치한다.
- 이미지별 크기·초점·조명을 비교하기 편하게 통일한다.

### 생물 정보 검수

- 게: 집게다리를 포함한 다리 10개, 눈 위치, 종별 집게와 무늬.
- 짱뚱어: 위쪽으로 돌출한 눈, 가슴지느러미, 실제 갯벌 서식 환경.
- 공통: 특정 종의 형태·색·서식지가 섞이지 않았는지, 사실과 설명이 일치하는지 확인한다.
- 확인되지 않은 사실을 단정하지 않는다. 생물을 함부로 채집하거나 오래 붙잡아 두지 않는 관찰 안내를 포함할 수 있다.

## 6. 장면별 자동 선택

| 핵심 목적 | 유형 |
| --- | --- |
| 인물의 표정·감정·행동 | A |
| 인물 사이의 상호작용 | A |
| 장소·계절·시간대·넓은 전경 | B |
| 생물 한 종류의 실제 특징 | C-1 |
| 여러 대상 비교·설명 | C-2 |

한 장면에 여러 목적이 있으면 주요 목적을 기준으로 선택한다. 필요하면 A/B 이야기 장면 아래에 C 학습 카드를 별도로 배치한다.

## 7. 프롬프트 구조

### A·B 조립 순서

```text
[1 BASE] → [2 FORMAT] → [3 TYPE] → [4 CHARACTER: PRIVATE]
→ [5 TIME/WEATHER] → [6 SCENE] → [7 NEGATIVE]
```

- 고정: BASE·FORMAT·CHARACTER(비공개 원본 참조)·NEGATIVE.
- 변경: TYPE·TIME/WEATHER·SCENE.
- 캐릭터 상세 고정문은 공개 문서에 직접 넣지 않는다.

**[1 BASE]**

```text
Warm, gentle cinematic 2D animated storybook illustration.
Beautiful hand-painted animation aesthetic, delicate clean linework,
soft painterly shading, rich environmental details, expressive characters,
atmospheric perspective, carefully composed scenery, directional natural
lighting, gentle rim lighting, luminous highlights, harmonious colors,
warm emotional storytelling. Detailed but not cluttered backgrounds.
```

**[2 FORMAT]** `4:3 landscape composition, important subjects not cropped.`

**[3 TYPE]**
- A: `Medium shot focused on the protagonist's action, expression and interaction.`
- A close-up: `Close-up emotional moment with the character's expression clearly visible.`
- B: `Wide establishing shot emphasizing scale, atmosphere, season and natural environment. The child is small in frame or absent.`

**[5 TIME/WEATHER]** 실제 원고에 맞는 시간대·기상·광원 한 줄.

**[6 SCENE]** 구체적인 장면, 인물의 행동, 장소와 관찰 포인트.

**[7 NEGATIVE]**

```text
No text, no letters, no captions, no speech bubbles, no collage,
no 3D rendering, no plastic-like surfaces, no photorealistic human faces,
no heavy black outlines, no cropped subject.
```

### C형 사진 생성 프롬프트

```text
High-resolution realistic natural history wildlife photography,
4:3 landscape composition, scientifically accurate anatomy,
authentic natural habitat, detailed textures, realistic colors,
natural daylight, sharp focus on key anatomical features,
educational wildlife field-guide quality. Leave clear composition
space for the required Korean title and discovery-note text overlay.
No exaggerated anatomy, no fantasy elements, no artificial colors.
```

**C형 제작 단계:** 실사형 관찰 이미지 생성 → 사실 검수 → **한국어 제목·설명 필수 작성** → 텍스트 합성 → 모바일·오탈자 검수. 최종 화면에는 반드시 글자가 보여야 한다.

## 8. 일관성·생성·수정

1. 작품별 골든 샘플(낮·밤 등)과 비공개 캐릭터 시트를 참조한다.
2. A·B 장면은 동일한 베이스·참조 이미지로 생성한다.
3. 장면별 이미지는 **각각 독립 생성**한다. 콜라주를 잘라 완성 장면으로 사용하지 않는다.
4. 수정할 때는 바꾸려는 요소를 명확히 지정하고 나머지 스타일을 유지한다.
5. 모든 장면을 나란히 비교하는 **콘택트 시트**로 색·인물·조명 일관성을 확인한다.
6. C형은 실사 생물의 형태 오류와 한국어 텍스트 오류를 각각 검수한다.

## 9. 파생 규격

- **표지:** A형 화풍의 포스터 구도. 제목은 HTML/CSS로 올리고 크롭 안전 영역을 확보한다.
- **지도·도해:** 정보 전달을 위한 선택적 C형 파생. 사진 대신 단순한 도해를 사용할 수 있으나 **제목·범례·설명 텍스트는 필수**다.
- 신규 기본 비율은 4:3. 예외는 사전 승인·기록한다.

## 10. 제작·배포

- 기본은 이미지 Base64를 포함한 단일 HTML. 작품별 선택에 따라 이미지 분리형도 허용한다.
- 일반 장면은 WebP 약 800px/품질 40에서 시작하되 실제 화질을 확인한다.
- **C형은 작은 글씨·생물 디테일을 위해 해상도와 품질을 높일 수 있다.** HTML 텍스트는 이미지 압축과 별도로 렌더링한다.
- 1~2MB는 단일 HTML의 권장 목표이며 필수 차단 기준은 아니다.
- 390px 모바일에서 C형 제목·이미지·발견 노트가 모두 보이고 가로 스크롤이 발생하지 않는지 확인한다.
- 원본 고해상도·개인 참조 이미지는 공개 저장소 밖에 둔다.

## 11. 영흥도 여행 적용 예시

| 장면 | 유형 | 제작 방향 |
| --- | --- | --- |
| 여행 가는 아침 | A | 설레는 표정과 여행 준비 |
| 바다가 보이는 도로 | B | 바다와 다리의 넓은 풍경 |
| 항구에서 배 구경 | A 또는 B | 감정 또는 항구 전경 중 주요 목적 선택 |
| 갯벌에서 게 발견 | A | 발견한 순간의 반응 |
| 옆으로 걷는 게 | C-1 | 사실적 게 사진 + **'옆으로 걷는 게' 제목·발견 노트** |
| 짱뚱어 관찰 | C-1 | 사실적 짱뚱어 사진 + **제목·발견 노트** |
| 갯벌 친구들 비교 | C-2 | 게·짱뚱어 이미지 + **각 이름·특징 설명** |
| 여행을 마치며 | A | 가족과 함께하는 마무리 |

이 표는 유형 적용 예시이며 기존 원고의 확정 장면 순서를 대체하지 않는다.
