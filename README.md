# 🦄 지아의 반짝반짝 책장

GitHub Pages 기반 공개 정적 그림책 도서관입니다. HTML 원고와 삽화를 버전 관리하며, 모바일에서 세로 스크롤로 읽습니다.

## 현재 수록
- `books/lulu-friends.html` — 《루루야, 나도 같이 놀아도 돼?》 (12장면)
- `books/jia-sea-otter.html` — 《지아와 해달의 신비로운 바다숲》 (10장면, 업로드된 원본 HTML 보존)

## 공개 절차
1. GitHub에 공개 저장소 `jia-storybooks`를 생성합니다.
2. 이 폴더 **내부 파일들**을 저장소 루트에 커밋합니다.
3. Settings → Pages → Deploy from a branch → `main` / `(root)`를 선택합니다.
4. `https://<GitHub 사용자명>.github.io/jia-storybooks/`에서 배포 결과를 확인합니다.

## 관리 방법
자세한 운영 기준과 새 책 등록 절차는 [`docs/BOOK_LIBRARY_OPERATIONS.md`](docs/BOOK_LIBRARY_OPERATIONS.md)를 참고하세요.

> 공개 사이트에 아동 실사진, 주소, 학교 등 식별정보를 넣기 전 공개 범위를 검토하세요.
