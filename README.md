# Kids Storybooks 📚

어린이를 위한 공개 HTML 그림책 도서관입니다. 원고와 삽화를 GitHub에 보관하고 GitHub Pages로 배포합니다.

## 도서 목록
- 《루루야, 나도 같이 놀아도 돼?》 — 12장면, 친구 관계·용기
- 《지아와 해달의 신비로운 바다숲》 — 10장면, 바다 탐험

## 운영 방식
1. `books/`에 HTML 그림책을 등록합니다.
2. `assets/`에 표지와 장면 이미지를 보관합니다.
3. `index.html`에 새 도서 카드를 추가합니다.
4. GitHub Pages로 공개하고 변경 이력을 커밋으로 관리합니다.

자세한 내용: [그림책 업로드·운영 가이드](docs/BOOK_LIBRARY_OPERATIONS.md)

배포 예정 주소: https://hahnjunhee.github.io/kids-storybooks/

> 그림책 HTML·이미지 업로드 및 Pages 활성화는 별도로 확인해야 합니다.
