# 🦄 반짝반짝 그림책 도서관

GitHub Pages 기반 공개 정적 그림책 도서관입니다. 모바일에서 세로 스크롤로 읽는(신규 작품은 페이지 넘기기 선택 모드도 제공하는) 생활·과학 그림책을 제공합니다.

**공개 책장:** https://hahnjunhee.github.io/kids-storybooks/

## 현재 수록
- `books/lulu-friends.html` — 《루루야, 나도 같이 놀아도 돼?》
- `books/sea-otter.html` — 《루아와 해달의 신비로운 바다숲》
- `books/yeongheung-seaside.html` — 《반짝반짝 영흥도 바다 여행》
- `books/craft-museum-gardener.html` — 《꽃을 피우다, 정원사》
- `books/korean-dinosaur-storybook.html` — 《루아와 공룡이 남긴 비밀》 (현재 v1.5)

- `books/korean-electric-eel-storybook.html` — 《찌릿찌릿! 전기뱀장어의 비밀》 (v1.0.1)

## 제작·운영 기준
- [그림책 제작 가이드라인 v3.1.2](docs/STORYBOOK_GUIDELINES.md) — 원작 보존, 별칭·개인정보, 캐릭터 일관성, HTML, 압축, 품질 검증, 게시
- [이미지 스타일 가이드 v2.4](docs/ILLUSTRATION_STYLE_GUIDE_V2.3.md) — 삽화 유형·품질 기준
- [도서관 운영 가이드](docs/BOOK_LIBRARY_OPERATIONS.md) — 새 책 등록, 공개 경로, 배포 확인

주인공의 기본 별칭은 **루아**이며, 작품별로 바꾸거나 생략할 수 있습니다. 실제 아동 이름은 공개 콘텐츠에 사용하지 않습니다.

## GitHub Pages
`main` 브랜치 루트에서 공개합니다. 커밋 완료와 실제 공개 URL 작동 여부는 구분하여 확인합니다.

> 과거 Git 커밋·외부 캐시에는 이전 이름이 남아 있을 수 있습니다. 이력 재작성은 별도 작업입니다.
